# API simulada de Pixel Game

Esta API usa json-server, siguiendo el ejemplo entregado en clases.

## Iniciar
1. Abre una terminal en esta carpeta (`api`).
2. Ejecuta `npm install` la primera vez.
3. Ejecuta `npm start`.
4. La colección de productos estará en `http://localhost:4000/products`.

Deja esta terminal abierta y ejecuta React desde una segunda terminal en la carpeta raíz del proyecto.

Los datos se guardan en `db.json`. Esta es una API local de práctica, no un servidor de producción.
